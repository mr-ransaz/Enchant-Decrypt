# Enchant Decrypt 0.1.0 — Minecraft 26.3

Preview enchanting-table offers before spending levels and lapis. Hover an offer to see the full result when certain, or only shared enchantments with a short hint when it is still ambiguous. Vanilla cost lines and colors are preserved.

- Passive client-side inference: manually swap a book and other items to calibrate on vanilla servers, without enchanting between observations.
- Optional exact results when a compatible server also has the mod.
- English and Russian text; the author's handmade icon.

Choose one asset:

- `mrransazenchantreveal-0.1.0+mc26.3-fabric.jar` — Fabric Loader 0.19.5 and Fabric API 0.164.0+26.3.
- `mrransazenchantreveal-0.1.0+mc26.3-neoforge.jar` — NeoForge 26.3.0.99; experimental.

Both builds target Minecraft 26.3 and Java 25. `SHA256SUMS.txt` contains the asset hashes. Do not install both loader jars together.

Client certainty is relative to vanilla selection rules, can require several observations and restarts after enchanting. Hidden server changes can differ. NeoForge's native server tests and startup smoke passed; in-world client and live-network compatibility sign-off remain open.
